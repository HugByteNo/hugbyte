# HugByte

**Independent web. Useful tools. Strange little side quests.**

`NORWAY / SMALL SYSTEMS / NO UNNECESSARY NONSENSE`

HugByte is an independent Norwegian workshop for software, practical AI, publishing experiments, music, and whatever else refuses to fit neatly into one category.

Some projects solve a real problem. Some make the internet a little less boring. A few started with *“this should take an afternoon.”*

## How this workshop operates

- **Static first.** Add servers and databases when the problem actually needs them.
- **Local-first where it makes sense.** Your data should not need permission to exist.
- **AI is a tool, not a business plan.** Human judgment stays in charge of the finished work.
- **Automate repetition, not decision-making for its own sake.** Prefer one useful script to six dashboards.
- **Ship small.** A finished narrow tool beats a majestic unfinished platform.
- **Keep the character.** The web has enough grey rectangles and corporate mission statements.

## About this repository

This is a **public project map**, not a source-code monorepo. It contains short introductions and links to independent HugByte projects; their actual code may live elsewhere, including in private repositories. A link here is not a claim that the corresponding product is open source.

Projects move, pause, and occasionally disappear. That's part of running a workshop instead of a corporate museum.
